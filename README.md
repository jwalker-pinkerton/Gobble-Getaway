# Gobble Getaway – Quiz 2 Review

A Thanksgiving-themed review game for Algebra 1 Quiz 2. Answer questions to help the turkey escape the farmer and reach the woods at step 15.

## How to play

Open `index.html` in any web browser. No install or build step needed.

- A correct answer moves the turkey one step.
- A wrong answer lets the farmer move one step closer.
- If the farmer catches up, the turkey throws a pie to distract him (3 pies total).
- Three correct in a row earns a "gobble dash" bonus step.

## Routes

- **Full review**: every Quiz 2 skill, mixed together
- **Slope and rate of change**: tables, the slope formula, horizontal and vertical lines
- **Graphing lines**: slope-intercept and point-slope form
- **Real-world graphs**: graph a story, then interpret points, slope, and y-intercepts

Questions are randomly generated, so every play-through is different. The results screen shows accuracy by skill and flags anything below 70% to review.

## Hosting with GitHub Pages

In the repository's **Settings → Pages**, set the source to deploy from this branch's root folder. The game will be served at `https://<owner>.github.io/<repo>/`.
